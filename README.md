# Course Resources

Course materials and examples for students. The first section is **Railway Reliability**, with BIS and Ofelia data examples.

- [Railway Reliability (English)](railway-reliability/index.en.md)
- [Järnvägsdriftsäkerhet (svenska)](railway-reliability/index.sv.md)

The documentation is available in English and Swedish. Code, identifiers, and filenames use English where practical.

## GitHub Pages

To publish this repository with GitHub Pages, select **Deploy from a branch**, choose the `main` branch and `/ (root)` in the repository's **Settings → Pages**. The root `index.md` is the landing page.

Do not commit database credentials, `.env` files, or data exports.
